**作成日**: 2026年4月2日

## 1. 概要

本IPはRSA-2048演算をハードウェアで実現するモジュールである。
RSAにおける暗号化・復号・署名・検証はすべて **モジュラー累乗（base^exponent mod n）** に帰着されるため、
単一の演算エンジンとして実装し、外部から鍵パラメータを与えることで全操作に対応する。

---

## 2. 機能要件

### 2.1 対応演算

| 操作 | 演算 | 使用鍵 |
|---|---|---|
| 暗号化 | $m^e \mod n$ | 公開鍵 $(e, n)$ |
| 復号 | $c^d \mod n$ | 秘密鍵（CRTパラメータ） |
| 署名 | $m^d \mod n$ | 秘密鍵（CRTパラメータ） |
| 検証 | $s^e \mod n$ | 公開鍵 $(e, n)$ |

全操作を単一のモジュラー累乗エンジンで実現する。

### 2.2 鍵・パラメータ仕様

#### 公開鍵演算（暗号化・検証）
- 入力: 底 $base$（2048bit）、指数 $e$（2048bit）、モジュラス $n$（2048bit）
- 指数 $e$ は任意値を入力可能とする（固定値に限定しない）

#### 秘密鍵演算（復号・署名）
- CRT（Chinese Remainder Theorem）用パラメータを入力とする
- 入力パラメータ:

| パラメータ | ビット幅 | 説明 |
|---|---|---|
| $p$ | 1024bit | 素数1 |
| $q$ | 1024bit | 素数2 |
| $d_p$ | 1024bit | $d \mod (p-1)$ |
| $d_q$ | 1024bit | $d \mod (q-1)$ |
| $q_{inv}$ | 1024bit | $q^{-1} \mod p$ |

### 2.3 データ仕様

- データバス幅: **32bit**（シリアル転送）
- 入力データ幅: 2048bit（32bit × 64サイクルで転送）
- 出力データ幅: 2048bit（32bit × 64サイクルで転送）
- キー長: 2048bit（RSA-2048）

## 3. 非機能要件

### 3.1 性能要件

| 項目 | 要件 |
|---|---|
| 目標動作周波数 | 100MHz |
| 処理方式 | 逐次処理（1演算完了後に次を受け付ける） |

### 3.2 インターフェース要件

- データバス幅: 32bit
- 制御インターフェース: Valid/Readyハンドシェイク
- 入力側: `valid_i` / `ready_o` により入力データの受け付けを制御
- 出力側: `valid_o` / `ready_i` により演算結果の出力を制御
- AXI-Liteとの接続はラッパーモジュールで対応する（本IPのスコープ外）

### 3.3 リセット要件

- アクティブLow非同期リセット（`rst_n`）

### 3.4 実装ターゲット

- ターゲットデバイス: Arty S7-25（Xilinx Spartan-7）
- 実装形態: FPGA

## 4. インターフェース仕様（概要）

詳細なポート定義は設計仕様にて確定する。以下は概要レベルの定義。

### 4.1 システム構成

```
外部システム（CPU等）
    │ AXI-Lite (32bit)
    ▼
┌─────────────────────┐
│  AXI-Lite Wrapper   │  ← 将来実装（本IPのスコープ外）
└──────────┬──────────┘
           │ Valid/Ready (32bit シリアル)
           ▼
┌─────────────────────┐
│    RSA-2048 IP      │  ← 本IPの対象範囲
│  (モジュラー累乗     │
│   コアエンジン)      │
└─────────────────────┘
```

### 4.2 共通ポート

| ポート名 | 方向 | 説明 |
|---|---|---|
| `clk` | 入力 | クロック |
| `rst_n` | 入力 | 非同期リセット（アクティブLow） |

### 4.3 入力インターフェース

2048bitのデータは32bit幅で64サイクルに分割してシリアル転送する。
どのパラメータを転送するかはアドレス（`addr_i`）で区別する。

| ポート名 | 方向 | ビット幅 | 説明 |
|---|---|---|---|
| `valid_i` | 入力 | 1 | 入力データ有効 |
| `ready_o` | 出力 | 1 | 入力受け付け可能 |
| `mode_i` | 入力 | 1 | 演算モード（0: 公開鍵演算, 1: 秘密鍵演算） |
| `addr_i` | 入力 | TBD | 転送先パラメータ選択（詳細は設計仕様で確定） |
| `data_i` | 入力 | 32 | 入力データ（32bitシリアル） |

### 4.4 出力インターフェース

演算結果も32bit幅でシリアル出力する。

| ポート名 | 方向 | ビット幅 | 説明 |
|---|---|---|---|
| `valid_o` | 出力 | 1 | 演算結果有効（1ワード単位） |
| `ready_i` | 入力 | 1 | 結果受け取り可能 |
| `data_o` | 出力 | 32 | 出力データ（32bitシリアル） |

## 5. 制約事項・前提条件

- 本実装は教育・学習目的であり、暗号ライブラリとしての安全性（サイドチャネル耐性等）を保証しない

- CRTパラメータの正当性チェックは本IPのスコープ外とする
